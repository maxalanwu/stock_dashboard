# 📖 欄位說明

各類筆記的 frontmatter 屬性說明。

- **自動**：`/update-stock`、`/daily-report` 會覆寫
- **手動**：使用者維護，自動更新不會覆蓋
- 百分比欄位寫純數字，例如 `change_pct: -0.4` 表示 -0.4%

## 個股筆記（`10_Stocks/`，模板：[[個股模板]]）

### 基本資料
| 屬性 | 說明 | 來源 |
|---|---|---|
| `code` | 股票代號，例如 `"2330"`，由檔名帶入 | 建立時 |
| `name` | 公司名稱 | 自動 |
| `market` | `上市` 或 `上櫃`。上櫃股改用 OTC 系列工具抓資料 | 自動 |
| `industry` | 產業別，須與 `30_Industry/` 產業頁的 `industry` 一致 | 自動 |
| `status` | `持有` 或 `觀察`，`/update-stock 持有` 依此批次更新 | **手動** |

### 價格與估值（自動）
| 屬性 | 說明 |
|---|---|
| `price` | 最新收盤價 |
| `change_pct` | 當日漲跌幅（%） |
| `pe` | 本益比（證交所公布值） |
| `pb` | 股價淨值比 |
| `dividend_yield` | 殖利率（%） |
| `eps_ttm` | 近四季單季 EPS 加總 |
| `eps_ttm_yoy` | EPS TTM 年增率（%）＝（EPS TTM ÷ 前四季 EPS 加總 − 1）× 100 |
| `peg` | 本益成長比＝（收盤價 ÷ EPS TTM）÷ `eps_ttm_yoy`；成長率或 EPS ≤ 0 時留空 |

### 營收（自動）
| 屬性 | 說明 |
|---|---|
| `revenue_yoy` | 最新月營收年增率（%） |
| `revenue_ytd_yoy` | 今年累計營收年增率（%） |

### 籌碼（自動）
| 屬性 | 說明 |
|---|---|
| `foreign_ratio` | 外資持股比例（%） |
| `foreign_net_5d` | 外資近 5 日買賣超（張），正數為買超 |
| `trust_net_5d` | 投信近 5 日買賣超（張） |

### 技術指標（自動）
| 屬性 | 說明 |
|---|---|
| `k` / `d` | KD 指標的 K 值、D 值（0–100） |
| `rsi` | 相對強弱指標 RSI（0–100） |

### 持股與交易計畫（手動）
| 屬性 | 說明 |
|---|---|
| `shares` | 持有股數，1 張 = 1000 股 |
| `entry_price` | 進場成本價 |
| `target_price` | 目標價 |
| `stop_loss` | 停損價 |

### 其他
| 屬性 | 說明 |
|---|---|
| `updated` | 最後自動更新日期（YYYY-MM-DD） |
| `tags` | 標籤，預設 `stock`，再加上產業名 |

## ETF 筆記（模板：[[ETF模板]]）

與個股共用 `code`、`name`、`market`、`status`、`price`、`change_pct`、籌碼、KD/RSI、持股計畫等欄位，沒有 `pe`、`pb`、EPS、營收。另外有：

| 屬性 | 說明 |
|---|---|
| `industry` | 固定為 `ETF` |
| `etf_type` | `指數型` 或 `主動式`（代號結尾為 A 或全名含「主動式」） |
| `dividend_yield` | 推算殖利率＝近 12 個月配息加總 ÷ 收盤價 × 100 |
| `dividend_freq` | `月配`／`季配`／`半年配`／`年配`／`不配息`，依近兩年除息次數判斷 |
| `top10_pct` | 前十大成分股合計占比（%） |
| `top1_pct` | 第一大成分股占比（%） |
| `margin_balance` | 融資餘額（張） |
| `tags` | `[stock, etf]` |

## 盤後日報（`20_Daily/`，模板：[[日報模板]]）

| 屬性 | 說明 |
|---|---|
| `date` | 交易日期 |
| `taiex` / `taiex_change_pct` | 加權指數收盤點數／漲跌幅（%） |
| `otc` / `otc_change_pct` | 櫃買指數收盤點數／漲跌幅（%） |
| `foreign_net_bn` | 外資買賣超（**億元**，欄位名雖為 bn） |
| `trust_net_bn` | 投信買賣超（億元） |
| `dealer_net_bn` | 自營商買賣超（億元） |
| `up_count` / `down_count` | 上漲／下跌股票家數（只算股票，不含權證） |

## 交易紀錄（`50_Journal/`，模板：[[交易紀錄模板]]，手動）

| 屬性 | 說明 |
|---|---|
| `date` | 交易日期 |
| `stock` | 個股筆記連結，例如 `[[2330 台積電]]` |
| `action` | `買進`／`賣出`／`加碼`／`減碼` |
| `price` | 成交價 |
| `shares` | 成交股數 |
| `reason` | 交易理由 |

## 產業頁（`30_Industry/`，模板：[[產業模板]]）

| 屬性 | 說明 |
|---|---|
| `industry` | 產業名稱，由檔名帶入，須與個股 `industry` 完全相同 |

## 首頁（[[首頁]]，手動）

| 屬性 | 說明 |
|---|---|
| `fee_discount` | 券商手續費折數，例如 `0.23` 表示 2.3 折，用於計算「賣出淨損益」 |
