# 📈 股票分析首頁

## 💼 持股
```dataview
TABLE name AS "名稱", price AS "股價", entry_price AS "進場價", choice(entry_price, round((price - entry_price) / entry_price * 100, 2), null) AS "報酬%", change_pct AS "漲跌%", pe AS "本益比", dividend_yield AS "殖利率", revenue_yoy AS "營收YoY", stop_loss AS "停損", target_price AS "停利價", updated AS "更新"
FROM "10_Stocks"
WHERE status = "持有"
SORT revenue_yoy DESC
```

## ⚠️ 跌破停損點
```dataview
TABLE name AS "名稱", price AS "股價", stop_loss AS "停損", rsi AS "RSI", foreign_net_5d AS "外資5日"
FROM "10_Stocks"
WHERE status = "持有" AND stop_loss AND price <= stop_loss
```

## 👀 觀察清單
```dataview
TABLE name AS "名稱", price AS "股價", target_price AS "停利價", pe AS "本益比", pb AS "PB", revenue_yoy AS "營收YoY", updated AS "更新"
FROM "10_Stocks"
WHERE status = "觀察"
SORT revenue_yoy DESC
```

## 🎯 觀察股低於進場價
```dataview
TABLE name AS "名稱", price AS "股價", entry_price AS "進場價", round((price - entry_price) / entry_price * 100, 2) AS "距進場價%", pe AS "本益比", rsi AS "RSI", updated AS "更新"
FROM "10_Stocks"
WHERE status = "觀察" AND entry_price AND price < entry_price
SORT (price - entry_price) / entry_price ASC
```

## 🌡️ RSI 過熱 / 超賣
```dataview
TABLE name AS "名稱", price AS "股價", rsi AS "RSI", foreign_net_5d AS "外資5日"
FROM "10_Stocks"
WHERE status = "持有" AND (rsi > 80 OR rsi < 20)
SORT rsi DESC
```

## 🕒 超過 7 天未更新
```dataview
LIST
FROM "10_Stocks"
WHERE updated AND date(today) - date(updated) > dur(7 days)
```
